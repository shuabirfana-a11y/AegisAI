# 本地演示与视频说明

按仓库根目录QUICKSTART_WINDOWS.md准备真实模型、数据库和服务，再打开工作台。不要在运行中的演示环境重复迁移或换库。

1. 展示情报监测、富化和调查三个入口及数据来源。
2. 选择真实API，输入明确的漏洞与组件版本，提交后展示本次新调查ID。
3. 查看实际任务Trace、Artifact、Evidence、Claim、Verification和Gate；保留未知及警告。
4. C08历史案例为langchain-core 1.2.0及相应维护分支，建议1.2.5；指定政策验收缺口须说明。
5. C09历史案例为vLLM 0.29.0，展示结构化版本范围与公告正文差异及引用。重新提交会生成新的模型输出，不能承诺重试过程与历史逐字相同。
6. 缺少必要版本时展示NEED_CONTEXT；冲突或支持不足时展示UNKNOWN或HUMAN_REVIEW_REQUIRED。

历史视频和完整录制素材留在本地归档，不把视频中的历史调查ID当作本次实时结果。本次未上传大型视频、逐帧缓存或含本机路径/凭证的原始录屏工程。当前仓库未提供公开视频链接，可按赛事平台要求另行提交审核后的成片。

首次克隆没有原演示机的库存、冻结公告和调查记录。先完成授权数据准备，禁止为了演示向新数据库插入虚假确认结果。当前GUI并非全量验收，建议桌面宽窗口展示；遇到错误应保留原响应。
