# 对照实验准备

本轮只规划，未实现或运行两个独立对照。旧代码有离线RAG等适配能力，但本轮完整HTTP正式入口中的可比独立对照仍为 NOT_IMPLEMENTED。

| 对照 | 计划流程 | 当前状态 |
|---|---|---|
| A：RAG-only | 相同冻结问题→相同公开信息语料检索→模型结构化答案 | NOT_IMPLEMENTED |
| B：无Verification Agent | 相同输入→独立实验调查路径→直接回答，不跳过生产Gate | NOT_IMPLEMENTED |
| C：AegisAI | 原公开HTTP→Planner→调查/核验/风险→Gate→AnswerEnvelope | 入口实现，本轮未执行正式实验 |

公平条件：相同测试题/可用资料和资产库存/数据截止时间；同模型不可变版本、预算和超时；模型输入均不含标准答案；统一输出Schema和独立输出复核；保留所有失败与耗时。不同流程的Prompt按角色冻结并公开差异，不强迫文本完全相同。B不能给生产系统加绕过核验开关。

仅相同URL、问题文件哈希或模型tag不能证明归一化语料、输入信息和库存等价，需要独立检查。尚未实现的一栏没有指标；不把缺少控制输出当0分，不宣称公平消融、因果提高或一等奖效果。
