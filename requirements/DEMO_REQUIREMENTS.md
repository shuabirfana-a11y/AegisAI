# 3—5分钟核心Demo需求

视频与现场演示由赛题明确要求；3—5分钟长度是用户/团队设计，原文没有时长规定。本文件只规划，当前不运行服务、Agent或采集，不制作假系统截图。

## 1 主路径（建议约4分钟）

| 段 | 内容 / 用户价值 | 证明与约束 |
|---|---|---|
| D1 0:00—0:40 | 真实类别与运行记录→选择一条AI情报 | 展示不同类别而非接口数量、来源及发布/首次获取时间；历史记录标回放，原始as_of不改成现在 |
| D2 0:40—1:30 | 详情→影响版本/评分/公告/文献/PoC候选 | 至少3种实际完成的富化维度；指出关联和可用性差别，未验证不计verified成果 |
| D3 1:30—2:10 | 打开Evidence/原文与未确定项 | 显示发布者、日期、locator；真实同scope冲突才进入复核；不同CVSS版本并列不假造“冲突解决” |
| D4 2:10—3:30 | 用户提出复杂问题→Agent实际选择工具→跨文档引用回答 | 主问题可问指定组件版本影响、修复依据、PoC状态；展示可观测工具/事实依赖，未知诚实；P1有授权资产时扩资产查询 |
| D5 3:30—4:10 | 运行/质量/限制作收尾，必要时展示受控故障恢复片段 | 展示真实评测范围/分母与恢复记录；提前录制故障片段注明回放，不把mock状态当真实故障 |

## 2 真实案例与必要前提

已有CVE-2025-32434和6产品种子可作为真实**历史案例**素材，后续经人工核验再用于Demo。它不是当前90天新增，不得改发布日期或伪称刚采集。其CNA CVSS4.0与NVD CVSS3.1数值不同是版本差异，不作为真实事实冲突。

PoC/patch、关联文章与明确fixed要有原始来源及审核记录；没有可用性验证则展示候选/未知。用户未提供真实库存，不能宣称已发现其受影响互联网资产；若演示配置必须显式标注“演示资产配置”，不能替代定位真实资产维度证明。实际资产能力以授权库存/暴露与关系证据验收。

最近90天复杂问题依当时真实snapshot/as_of筛选，可能空结果；问“有已核验PoC”时不能把未审仓库算进去。Demo可用不受90天限制的历史案例主问答，保持时间真实。没有真实冲突时展示来源版本差异、缺失和复核能力边界，不编造冲突数据。

## 3 展示验收及材料

点击关键结论能回到原文；现场Agent/工具轨迹来自实际运行；录屏/回放有标签；出错有解释与已知数据回退；没有secret/私有资产外泄。说明当前支持范围和未确认项，保持视频、技术报告、PPT与评测结果一致。

初赛：Word/PDF报告、演示视频、讲解PPT的PDF；报告应含总体/Agent/三模块详细设计、选型/流程、实现/核心代码说明、效果、性能测试和创新，重要亮点预览页是原文建议而非强制格式。源代码企业参赛平台审阅，不另公开打包。

决赛：主办模板答辩PPT（不含单位、人名等识别信息）、Word/PDF报告、视频；答辩准备解释分类/维度计数、真值/分母、lineage、失败/unknown和对照实验证据。题面未规定答辩时间、视频编码和审阅接入细则，后续按官方通知落实，不凭空设为官方要求。


需求属性与来源的完整登记以 [FEATURE_LIST.md](FEATURE_LIST.md) / [requirements.json](requirements.json) 为准；具体实现尚未开始。
