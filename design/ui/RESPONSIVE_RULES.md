# 响应式规则

比赛优先1440×900，同时确保1280×900正常。已在浏览器对七页分别检查1440、1280、1024、768宽度；没有整页横向溢出。1440与1280截图以及异常状态截图供内部评审，浏览器结果见browser_validation.json。

| 宽度 | Layout | 密度与降级 |
|---|---|---|
| ≥1440 | Sidebar216/Header64/main28，详情正文+246辅助栏 | 总览主列表/右侧趋势与组件；Review双候选；问答300过程栏 |
| 1280—1439 | Sidebar200/main22，详情辅助215 | 风险字段2×2；工作区侧队列260；正文不压成小字 |
| 1024—1279 | Sidebar180，详情辅助改为流式 | 必要表格在自身容器横滚；Review两候选可上下对照 |
| 768—1023 | Sidebar64图标栏，保留aria-label/title | 工作区、问答与总览改单列；评审状态控件可隐藏；产品主要路径可走 |
| <768 | 仅基本可用，不作为首期适配重点 | 表格容器横滚、抽屉全宽、控件换行；不投入移动专属页面 |

Sidebar稳定，细栏图标仍有可访问名称；顶部全局搜索保留，示例日期可在中等宽度隐藏，mock标识始终可见。原型评审控件属于桌面工具，不纳入移动产品导航。

长ID/Hash/locator允许break-anywhere；普通标题换行，完整文字不藏在hover里；Table列最小宽度与横滚独立，禁止让body横滚。Drawer ≤590px且不超过viewport，Modal ≤650px/max-height并可滚动；关键提交按钮不被背景内容覆盖。

Default正文14/表格13—14；Compact只减padding，不以11px塞更多记录。浏览器Zoom、不同中文字体fallback、触屏及全面读屏仍需后续前端验证，本轮不声称全设备无障碍完成。
