# AegisAI 视觉方向

面向AI生态的可信安全情报系统。视觉以专业分析工具为目标：浅色、克制、可读、可审计。重点是结论旁边的范围、核验状态与证据入口，避免用户只看见风险颜色却不知道依据。

## 已选方向与备选取舍

采用冷中性背景、白色内容面和低饱和青绿操作色。固定216px左侧导航、64px顶部搜索、主区28px边距；沿用Phase 3六个一级导航、七个核心页，不新增业务菜单。表格和章节分隔承担结构，少量卡片只用于聚合指标、风险字段与证据。

深色安全控制台不适合作为首版：颜色难同时承担严重度、核验及数据时效，日常阅读长证据成本更高。卡片大屏不适合：信息孤立，妨碍产品/版本/来源对照。Light Mode优先，本轮不制作Dark Mode或主题切换。

基础色：背景 #F5F7FA、内容面 #FFFFFF、主文本 #1E293B、次文本 #526173、边界 #D7DFE8、操作 #0F766E。风险与核验使用独立语义色，所有颜色同时伴随文字/图形，未知从不画成绿色安全。

## 文字和视觉记忆点

Segoe UI配Microsoft YaHei UI用于界面，Cascadia Code/Consolas用于ID、版本、SHA和定位。标题26px，正文14px，表格13—14px，辅助12—13px，解释性长文行宽控制。不用全大写标签、夸张Hero、机器人、星光、蓝紫渐变或粒子。

唯一强调处是“结论—依据”的并排层级：Claim摘要在上，来源与核验清楚分列，Evidence以细边界和来源条签承接；冲突两列对照但不染红整个页面。品牌仅一个字母标记，不铺满盾牌。

## 原型边界

prototype/只用本地HTML/CSS/JS与明确标注的模拟数据，所有模拟CVE均为CVE-XXXX-…；没有API/模型/数据库/采集。P1页面可在原型评审时查看并标P1，不代表已实施能力。实际前端必须按capabilities门控。Design System服务后续组件实现，本轮不选择React/Vue或正式工程。

设计前自检已删除：深色主主题、单独聊天浮窗、额外知识一级导航、每模块套卡、巨大风险总分和装饰地图。保留顶部搜索、来源日期、字段状态、证据回链及真实工具过程所需版位。
