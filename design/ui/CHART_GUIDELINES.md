# 图表规范

每个图必须回答问题，并能说明数据范围、时间口径和未知。当前总览仅保留一条7天趋势：“这个观察窗口内新增去重情报的变化怎样？”并用原型“仅示例趋势，非实测”标签；不把趋势当Benchmark或系统实时监测证明。

## 数据与形状

趋势线用于时间序列，Bar用于清晰的类型数量比较，Stacked Bar只在类别互斥且合计可解释时用；本轮不增加额外Bar或Donut。坐标/单位/日期可读，tooltip不是唯一数值渠道，生产需提供文本表。示例SVG具备aria-label及全部7个数值，无动画/联网依赖。

新发现以first_observed去重主体，更新为existing entity revision变化；知识按paper/standard/policy，不能CVE数量代替全部情报。比较用同as_of/coverage/窗口；raw抓取数不当新增数。源published未知样本不纳入延迟统计，显示样本数及排除量；空序列显示无数据，不能画0线误导。

原型overview的“本期AI漏洞”是8条模拟集合，点击进入同一集合；3条严重/高危及3条已关联PoC都能回查对应筛选。7天趋势单独为模拟序列，不冒充这8条的first_observed统计。生产切到真实服务后必须按Phase 3 D01/D02规范使用时间窗与观察记录。

颜色只区分有限序列，图例、文字、必要符号同时存在；严重度与核验不混入同色图例。没有Radar、3D Pie、Gauge、世界地图或“AI安全指数”。不添加预测曲线或准确率数值，除非后续评测有真值、样本及可复现记录。

BACKEND REQUIRED D01/D02/D04：聚合源、去重/版本记录、时间/coverage，以及能回到实际结果的filter契约。原型图不是该后端已实现的证据。
