# UI自检与交付边界

七个高保真核心页已建立可运行离线原型；Light Mode、Default/Compact、关键共享组件和页面状态规范已形成。本文区分浏览器/视觉检查与尚未实现的业务能力。

## 去模板感检查

没有Hero、蓝紫渐变、玻璃拟态、粒子、机器人/星光、世界地图、发光边框或AI Powered装饰文案。原型详情初稿每节独立边框较碎，已合并成连续调查文档；表格六组信息，不堆20列。总览只四指标和一个有问题导向的趋势，不添加无证据综合安全分。

资产/Review/问答以任务为工作区，不复刻气泡聊天或通用审批；知识入口保留论文/正式标准/政策。色彩同时配状态名称，严重度与Claim核验独立；PoC相关和可用性分开。缺数据保留—/未知，研究probe不当运行。

## 评委30秒视角（设计走查，非用户实测）

总览标题/导航标明AI安全情报；列表显示AI组件与来源；详情优先版本、PoC、KEV、明确fixed/Patch及可点Evidence；Review同scope候选对照；资产三态及原因；问答结构化结果/引用与工具摘要；系统run与最后成功分开。所有原型页面始终标模拟，不能凭界面说明实际实时监测已完成。

## 浏览器检查

已对七页检查1440×900、1280×900，并对1024/768基本可用性测量；只允许表格局部横滚，整页无横向溢出。七页Loading/Empty/Error/Partial/Stale均有截图；Evidence抽屉、Agent超时与失败SyncRun另有截图。最新通过数与时间以browser_validation.json为准。

交互检查：metric与过滤集合相符、筛选/分页/详情返回、精确ID搜索、知识身份、模糊版本澄清、新资产unknown、Review预览/前后值/actor/理由、返回详情人工层、只读权限禁提交、超时引用回证据、重试仅queued、无外部请求/JS或CSP错误。

已修正：HTML pattern在UnicodeSets模式不兼容；跳转检查先读取旧DOM产生误报，改成等待目标内容；详情容器过碎；Source名称内部化；窄屏导航名称；人工审计只保存选择名而缺候选值/暂缓状态。程序检查不会取代视觉审阅，最终截图已逐页走查，视觉记录见visual_review.json。

## 当前仍需后续验证的项

1. 生产capabilities/auth、API、版本判断、Source/SyncRun、Agent和Review并发均未实现；固定Mock不是功能成绩。
2. 原型新增组件只做基础输入示例校验，不是PEP 440/SemVer引擎；名称/版本歧义交给正式后端契约，新增影响保持unknown。
3. 完整Multi Select/任意日期选择弹层、长列表性能、全套键盘Tab roving/读屏和跨浏览器/字体/Zoom仍需真实前端验证；不宣称全面WCAG认证。
4. Tablet仅基本可用，Mobile与Dark Mode未优先开发。桌面未发现未解决的明显裁切/溢出；真实长证据和实际密度需服务数据再次验证。
5. 模拟人工决定仅当前内存，刷新恢复；固定问答不能回答任意输入。运行和队列示例不会真正发任务，重试绝不假显示成功。

完成后停止。下一阶段是数据库与核心数据模型设计，本轮没有建表/写后端/Collector/Dify/Agent或生产前端。
