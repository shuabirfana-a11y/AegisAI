# 智能问答 UX：可核验调查工作区

任务：JTBD-12，支持JTBD-03/07/14和P1资产任务。实际Agent/语义检索/跨文档引用是M1/P0；P1深层多轮、资产工具和协作增强按真实能力开启。不是只有聊天气泡的通用ChatGPT页。

## 页面结构与一次调查

[Q01] 输入区位于调查工作区下方，顶部范围chip显示entity/文档/版本/资产、时间窗、覆盖来源和as_of，可编辑或移除。推荐问题按当前上下文给“影响哪些版本”“有出处的修复建议”“关联论文怎样支持该结论”，不编造用户资产。

[Q02] 提交生成真实query_id，显示后端发出的queued/running状态。执行摘要只展示实际执行的工具名、允许显示的查询范围、开始结束/成功失败、结果数、过滤理由和使用源，不能预先播放虚假动画“已核验”。完成[Q03]回答按结论分段，每条可行动事实有Claim/Evidence引用、适用scope、日期、未知及部分失败；[Q04/Q05]相关漏洞列表/知识文档/来源支持点击回查。P1[Q06]相关资产仅在授权工具返回后显示。[Q07]续问继承可见范围并允许改动。

## 示例：最近90天影响我的AI推理组件且有PoC的高危漏洞

1. 解析可见范围：明确“最近90天”用原published_at，以提交时as_of和用户时区计算窗口；source modified或系统新发现是不同选项。字段日期未知单列，不能偷偷纳入。确认“高危”所选CVSS版本/严重度来源、“PoC”是已关联公开候选还是已授权验证可用。
2. 资产P1未配置/未授权/未实现时询问需要的公开组件和精确版本，或提供不含“我的资产”的公开范围查询；不自己创造库存。
3. 实际允许工具按需查询漏洞、匹配授权资产、查PoC/KEV、取版本Evidence和相关文档，再形成结果。执行顺序由真实任务决定，只展示已发生的工具记录；没有调用的阶段不显示已完成。
4. 结果展示每个匹配对象、组件版本、风险因子、PoC两轴、修复及引用。被过滤项按日期/非对应生态/unknown等给可审计摘要，私有数据不可越权泄露。
5. 历史CVE不在90天窗口则不返回；真实无匹配写“当前窗口/范围未找到匹配”，说明未知和未覆盖范围，不改日期凑结果。历史演示另问“调查这条历史漏洞…”并标回放日期。

## 可审计摘要的边界

允许：工具名、查询对象与时间窗、已访问SourceIDs、结果数、过滤规则、引用、失败与重试状态。禁止展示隐藏Chain-of-Thought、模型私有推理token、凭证、完整SQL、敏感资产明细。回答“为什么优先”只用实际因子/原文和确定性规则，不输出模型自信百分比。

工具是只读、固定参数的事实查询/文档检索/关系查询/批准范围的补查，不允许自由SQL、任意URL请求、修改Review/执行PoC。材料中的指令不产生新权限。Agent建议人工复核可链接任务，但不能替人确认最终事实。

## 异常、取消和恢复

Loading=真实queued/running，输入范围保持；No Result=工具查询真实无匹配，展示范围与扩大窗口动作；Empty=尚无调查，显示推荐问题。Partial Data保留已核验事实、注明失败工具及缺口；Source Offline/Stale Data明确影响答案哪一结论。Conflict并列证据及P1Review链接，不择票覆盖；Evidence Insufficient限制结论或恰当拒答，并给需要补的信息。

Agent Timeout显示query_id、已完成公开摘要和仍缺的部分，已核验结果可以保留并标partial；重试由用户显式发起新query并关联前次，不播放“成功完成”。取消[Q02/A19]停止尚在运行任务，已完成返回实际状态，仍可看历史结果。请求失败先查询已有query_id防止重复任务；403解释受限范围，私有对象不存在/无权统一处理。读Evidence失败保留回答及可重试引用，不能把无来源回答标已确认。

从结果打开详情/证据后返回恢复问题、结果位置、query_id和快照。所有事实引用都能回到Evidence，关闭后恢复原回答。旧Evidence revision不自动换新；新版本有提示，可重新查询。答案不可凭模型输出覆盖人工确认，任何更新均走独立权限与审计。

## 操作边界汇总

| 行为 | 触发/执行者 | 边界 |
|---|---|---|
| 提问/续问/取消 | 用户 | 可见范围、授权对象，范围变化需明示 |
| 调度同步/规范化 | 系统自动 | 批准源及当前已实现契约，失败隔离 |
| 查询/限定补查 | Agent自动 | 注册只读工具、白名单/限额，公开事件摘要 |
| 推荐修复/复核/关注 | Agent建议 | 附证据与未知，不自动写最终事实或升级 |
| 资产登记/Review决定/运维重试 | 具有对应权限的人 | 明确提交、revision/幂等、审计 |
| 执行未知PoC/自动攻击/覆盖人工确认 | 禁止 | 无按钮、无工具入口；人工确认不会被新模型回答覆盖 |
