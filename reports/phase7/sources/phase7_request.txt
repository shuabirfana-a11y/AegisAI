你现在开始 AegisAI Phase 7。

# Phase 7
情报富化 + POC/Patch/Vendor/EPSS + Claim/Evidence + 多源核验

Phase 1~6 已经完成。

不要重新实现 Phase 6。
不要大规模重构已经正常工作的 Collector / Normalizer / Dedup / Database。

本阶段是在 Phase 6 已经形成的真实情报数据链路之上，
建立 AegisAI 最核心的“可信安全情报”能力。

==================================================
0. 本阶段核心目标
==================================================

Phase 6 已经解决：

“发生了什么漏洞？”

Phase 7 要进一步解决：

这个漏洞到底影响谁？
影响哪些版本？
有没有真实 POC？
有没有 Patch？
官方怎么说？
是否已经被利用？
不同来源说法是否一致？
我们凭什么得出这个结论？
如果证据不足，系统能不能明确说不知道？

完整流程：

Vulnerability
↓
Enrichment Planning
↓
Vendor / Advisory / EPSS / KEV / GitHub / Security Source
↓
Candidate Discovery
↓
POC / Patch / Fix / Version / Exploitation Enrichment
↓
Claim Generation
↓
Evidence Extraction
↓
Cross-source Verification
↓
Conflict Detection
↓
Verification Status
↓
Trusted Intelligence

最终必须形成：

“结论 + 证据 + 来源 + 时间 + 核验状态”

而不是：

“LLM说这是对的”。
