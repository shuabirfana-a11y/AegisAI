# 五步开始人工标注

对象：标注人和独立复核人。当前首批 10 题资料已备，人员未分配，人工完成与批准均为 0。

1. **领取题目。** 从[首批工作单](../annotation_tasks/batches/batch_01/BATCH_WORKBOOK.md)选原 ID，管理员登记你和另一位不同真人的团队 ID；读完整问题、输入和[角色手册](ANNOTATOR_TASK_MANUAL.md)。
2. **查官方资料。** 亲自打开原公告，核对包、分支、版本边界和时间。候选资料只是入口，不看机器参考答案；证据不足保留未知。
3. **填模板。** 复制[空白表](../ground_truth_template.json)，原题不改；填写标准答案、逐项判断、原文、URL、两种时间和缺口。具体见[证据要求](EVIDENCE_REQUIREMENTS.md)。
4. **提交复核。** 填完后请管理员核对字段、修订和内容哈希，交给第二人按[复核手册](REVIEWER_TASK_MANUAL.md)亲自查源、逐项签核；一句“同意”不算完成。
5. **按意见修订。** 退回写明原因，保留旧版本，新修订重新复核。实际通过才 APPROVED；数据经 PR 提交，不直接改 main。

提交材料：原 ID、人工表单路径、修订号、内容哈希、证据入口和待确认点。身份、查源确认与时间必须真实。

牢记：**候选不等于验证；未知可以合格；AI 不替真人签署。** 本轮不运行 POC、不执行评测、不填写或修改已冻结的机器答案。

状态区别和文件保存方法见[LABELING_PROCESS.md](LABELING_PROCESS.md)；字段以[原说明](../MANUAL_RECORD_SCHEMA.md)为准。
