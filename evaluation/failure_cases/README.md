# Phase12D.2 失败案例

这些文件用于工程和业务失败分析，不是Ground Truth、标准答案或正式Benchmark数据。不要导入Approved Dataset。

`historical-component-version.json`来自Phase12D.1真实模型调查的只读审计。计划合法、版本工具执行成功；最终Gate FAILED。每条规则保存原blocking等级、关联Artifact和缺失信息。

后续扩展回执必须分别标注真实来源、示范库存或合成控制。示范库存不证明真实服务器已安装某组件；来源冲突记录也不等于独立核验确认了事实冲突。

类型A：Schema缺失；类型B：接口适配；类型C：业务逻辑/业务契约；DATA：库存、证据或来源缺口。C与DATA本轮只报告，不改变Agent/Gate。
